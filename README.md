# Interface Networld™ Legal & Privacy Repository

This repository stores baseline legal and privacy documents for Interface Networld Software Corporation and InterfaceNetworld.com.

## Documents

- `PRIVACY_POLICY.md` — privacy practices and user rights.
- `COOKIE_POLICY.md` — cookie categories, session cookie details, consent, and browser controls.
- `COPYRIGHT_TRADEMARK_NOTICE.md` — copyright ownership, claimed trademarks, and trademark-symbol guidance.
- `WEBSITE_FOOTER.md` — approved short-form and extended legal footer copy.
- `Privacy Policy.pdf` — previously stored privacy-policy document.

## Deployment Review

Before publishing these files as final legal terms, verify that the language matches the production application’s actual data collection, analytics, advertising, payment providers, AI/model vendors, retention practices, and jurisdiction-specific requirements.
